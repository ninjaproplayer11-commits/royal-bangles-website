# Royal Bangles E-commerce Website

A modern, premium e-commerce website for Royal Bangles built with React and Tailwind CSS.

## Features

- Elegant, luxury design with gold, beige, white, and soft pink colors
- Responsive design
- Multiple pages: Home, Shop, Product Detail, About, Contact, Cart, Checkout
- Smooth animations and transitions

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm run dev
   ```

3. Open your browser to `http://localhost:5173`

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- React Router
- Vite
